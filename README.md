# TRNR - AI Voice Conversation UI

A minimalist Next.js application showcasing a clean voice conversation interface with an AI agent.

## Features

- Connect/disconnect button for AI agent
- Animated waveform indicator when agent is speaking
- Clean, minimalist design

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
